GeoIP and ASN

IP locations work with no setup. SIEMLite downloads the free DB-IP "lite" City and ASN databases itself, and every public source and destination IP then gets a country, city, coordinates and autonomous system as it is stored.

  • What is downloaded, and from where. Two files from download.db-ip.com over HTTPS: the City database (about 60 MB, 130 MB unpacked) and the ASN database (about 5 MB, 10 MB unpacked). Nothing about your events or your server is sent: it is a plain download.
  • When. DB-IP publishes a new edition each month. SIEMLite looks for one at every start (which includes the one after each update) and whenever it checks for updates, by hand or on the automatic update schedule, and swaps it in without a restart. A file is only downloaded when there is a newer month than the one you have; older editions are deleted. A failed download never replaces a working database, and never holds up an update.
  • Where it is kept. geoip/ next to the database (/data/geoip in the container), as dbip-city-lite-YYYY-MM.mmdb and dbip-asn-lite-YYYY-MM.mmdb, about 140 MB together.
  • The System page has an IP locations panel: a switch (on by default), which editions you have, when it last checked, what went wrong if it did, and Check now. Hovering an IP in the Database says why it has no location when it has none.
  • Turn it off with that switch. Downloaded files stay on disk but are not used, and nothing is fetched.
  • Air-gapped, or you want MaxMind? Turn the switch off and give your own files instead; they win, and nothing is downloaded:
./siemlite -geoip-city GeoLite2-City.mmdb -geoip-asn GeoLite2-ASN.mmdb
  • Your own files can be MaxMind GeoLite2 (free with an account; keep it fresh with geoipupdate) or GeoIP2, or DB-IP files you fetched yourself. A Country database works in place of City. Either flag can be used alone. They are checked hourly and reloaded when they change, so geoipupdate needs no restart. The System page then says "Using your own database files."
  • Private, loopback and other non-public addresses are skipped.
  • Search with country=CN or asn=AS4134 (either endpoint). The country code shows next to each IP in the UI; the full location and AS name are in the event detail.
  • Attribution. The downloaded data is IP geolocation data by DB-IP.com, licensed under CC BY 4.0. The page credits DB-IP where it shows it; if you republish the data, keep that credit.

Only events stored after the databases are in place are enriched; earlier events keep what they had.

IP addresses in the UI

Wherever an address is shown (the Database and its event details, alerts, the Dashboard's threat-listed IPs, threat matches and reports) it is underlined.

  • Hover for its location, network and threat lists. When there is no location, the card says why: GeoIP isn't set up, the IP isn't in the database, or it was stored before location data was on.
  • Click to search SIEMLite for it (ip=<address>, source or destination). Ctrl/Cmd-click opens the search in a new tab.
  • Right-click it, or press the ContextMenu key or Shift+F10 on it, for a small menu: TALOS Lookup (opens Cisco Talos in a new tab; nothing is sent to Talos until you choose it) and, for admins, Add to list, which adds the address to one of your friendly lists (with an optional note) from a dialog.
