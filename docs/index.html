SIEMLite wiki

SIEMLite is a lightweight, embedded SIEM in a single Go binary. It collects logs over HTTPS or syslog, normalizes them to the OCSF event model, stores them in SQLite (one file per day) and gives you full-text search through a built-in web UI and a small JSON API.

This wiki is the full documentation. The README has the short version. Current release: latest.
