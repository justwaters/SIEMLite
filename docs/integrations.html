Integrations

The Integrations page lists the services SIEMLite can connect to. Each is built in, and appears as a card with a state (Not set up, Off, On, or Problem), an On switch, and a Settings button that opens its settings. Set an integration up first; the switch then turns it on or off without losing its settings. Only admins see the page, and turning one on or off is recorded in the audit log.

SIEMLite is free and open-source software under the GNU AGPL-3.0. These pages also live in the project wiki.
