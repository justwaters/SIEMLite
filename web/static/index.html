        Intel

        Threat feeds

        Free lists of known-bad IP addresses, downloaded every 6 hours (a newly chosen one right away). Any event that mentions a listed address is marked as a threat. Each list’s own terms decide whether you may use it where you work; read them before choosing one. Nothing is downloaded until you choose it.

        Friendly addresses

        Addresses and ranges you trust, such as your office, a partner or a scanner you run. A friendly address is never marked as a threat, even if a feed lists it. This applies to events stored from now on; it doesn’t change events already in the database.

        Coming soon

        Known vulnerabilities (CVEs) will be matched against the software your logs mention, so you can see which weaknesses are being probed or exploited. Not built yet.

        Slack

        …

        Post a message to a Slack channel whenever SIEMLite opens an alert.

        In Slack, create an app with an incoming webhook (api.slack.com/messaging/webhooks), pick the channel, and paste its address here. The address works like a password, so SIEMLite keeps it sealed and never shows it again. At most 10 messages are posted a minute; if more alerts open, the next message says how many were held back.

        In Teams, add a workflow to the channel with the trigger “When a Teams webhook request is received” and the action “Post card in a chat or channel”, then paste the workflow’s address here. The address works like a password, so SIEMLite keeps it sealed and never shows it again. At most 10 messages are posted a minute; if more alerts open, the next message says how many were held back.

        Microsoft Entra ID

        …

        Let the people in an Entra group sign in to SIEMLite with their Microsoft account.

        Checking…

        How to set this up in Microsoft Entra
        1. In the Entra admin center, open App registrations and choose New registration. Pick Accounts in this organizational directory only. Under Redirect URI, choose Web and paste the Redirect URL shown below.
        2. On the app's Overview page, copy the Directory (tenant) ID and the Application (client) ID into the fields below.
        3. Under Certificates & secrets, create a New client secret and copy its Value (it is shown once).
        4. Under API permissions, choose Add a permission, Microsoft Graph, Application permissions, add GroupMember.Read.All, then choose Grant admin consent.
        5. Open the group whose members may use SIEMLite and copy its Object ID. To make some people Admins, do the same for a second group. Everyone else in the access group is a Standard user.

        SIEMLite checks the group at every sign-in and every five minutes, and switches off anyone who has left it. Keep a local admin account in case Microsoft is unreachable.

        AI Alerts

        …

        A model reads a summary of your recent logs now and then and proposes alert rules to add.

        Checking…

        Each look gives the model counts and examples from your logs, plus the rules you already have, and asks what is worth catching. It only proposes: a rule changes nothing until you accept it, and it never raises, closes or edits an alert itself. SIEMLite’s own audit events are left out, and every look is recorded in the audit log.
