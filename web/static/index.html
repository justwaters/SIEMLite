        Add source

        A source is an application or device that sends logs to SIEMLite. The next screen shows how to connect it.

        Connect source

        Point the application at SIEMLite and give it the access token below. The token can only send logs.

        Send logs to

        Change this to the address your apps use to reach SIEMLite if it differs from the one in your browser.

        Access token

        This is the only time it’s shown. If it’s lost, disable or delete the source and add another.

        Send a log

        SIEMLite’s certificate is self-signed unless you supplied your own, so clients must trust siemlite.crt, as the snippets show. With Docker the file is /data/siemlite.crt; copy it out with docker compose cp siemlite:/data/siemlite.crt . and remove the lines about it if the certificate is already trusted.

        What comes back: 202 accepted; 401 the token is wrong or the source is disabled; 503 busy, so wait Retry-After seconds, then send again.

        Add logs

        Paste logs, one per line, or load a file. They’re stored under “Added in the UI” and read with its parser.
