        Microsoft Entra ID

        …

        Let the people in an Entra group sign in to SIEMLite with their Microsoft account.

        Checking…

        How to set this up in Microsoft Entra
        1. In the Entra admin center, open App registrations and choose New registration. Pick Accounts in this organizational directory only. Under Redirect URI, choose Web and paste the Redirect URL shown below.
        2. On the app's Overview page, copy the Directory (tenant) ID and the Application (client) ID into the fields below.
        3. Under Certificates & secrets, create a New client secret and copy its Value (it is shown once).
        4. Under API permissions, choose Add a permission, Microsoft Graph, Application permissions, add GroupMember.Read.All, then choose Grant admin consent.
        5. Open the group whose members may use SIEMLite and copy its Object ID. To make some people Admins, do the same for a second group. Everyone else in the access group is a Standard user.

        SIEMLite checks the group at every sign-in and every five minutes, and switches off anyone who has left it. Keep a local admin account in case Microsoft is unreachable.

          Send a log

          SIEMLite’s certificate is self-signed unless you supplied your own, so clients must trust siemlite.crt, as the snippets show. With Docker the file is /data/siemlite.crt; copy it out with docker compose cp siemlite:/data/siemlite.crt . and remove the lines about it if the certificate is already trusted.

          What comes back: 202 accepted; 401 the token is wrong or the source is disabled; 503 busy, so wait Retry-After seconds, then send again.
