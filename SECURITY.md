# Security Policy

## Reporting a vulnerability

Please report security issues privately by email to **justin@1waters.com**. Do not open a public issue or pull request for a suspected vulnerability.

Include the affected version (`siemlite -version`), a description of the issue, and steps to reproduce if you have them.

## Supported versions

Only the latest release receives security fixes.

## Past reviews

Findings from earlier reviews, including risks that are accepted by design, are documented in [SECURITY-AUDIT.md](SECURITY-AUDIT.md).
